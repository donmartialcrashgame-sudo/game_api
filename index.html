FAQ

Questions, answered

Can visitors place bets from this page?

No. The public homepage is intentionally view-only. It displays live WebSocket information and contains no betting controls.

Where does the multiplier come from?

The frontend reads the value from the configured WebSocket. It does not calculate or invent the crash multiplier.

Can I create an account without a passkey?

Yes. Passkeys are an additional authentication method. We can offer them after account creation and let supported users use them for later sign-ins.

Will Google Authenticator be required for everyone?

Initially, users without TOTP can enter the dashboard and receive a prompt to set it up. Users who already have TOTP must complete the MFA step before accessing protected areas.

Will the football section affect the crash engine?

No. The football presentation should remain a frontend visual layer while the server remains the authority for game events.

Can the homepage contain many sections?

Yes. This page is intentionally structured as a long scrolling landing page so we can keep adding platform, security, game and developer sections.
